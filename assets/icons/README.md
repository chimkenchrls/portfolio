The social brand marks used by Links come from Simple Icons:

- [Discord](https://github.com/simple-icons/simple-icons/blob/develop/icons/discord.svg)
- [TikTok](https://github.com/simple-icons/simple-icons/blob/develop/icons/tiktok.svg)
- [Facebook](https://github.com/simple-icons/simple-icons/blob/develop/icons/facebook.svg)

They are stored locally and rendered as CSS masks. The other UI icons use the site's existing stroke style.
